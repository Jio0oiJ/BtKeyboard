# BtKeyboard

> **下载 APK**：[v1.7.3 release](apk/BtKeyboard-v1.7.3-release.apk)（可直接安装，签名与旧版一致，无需重新配对）

把 Android 手机变成**蓝牙 HID 键盘 + 触控板**，通过蓝牙连接电脑使用。基于 Android 9+ 的
`BluetoothHidDevice`（API 28+）实现，纯框架 API，无第三方依赖。

## 功能

- **全盘 26 键主键盘**：手机输入法风格的 5 行大键布局，字母区尽可能放大。
- **多页签布局**：主键盘、触控板、编辑/数字小键盘、符号（含 F1–F12）、快捷组合键。
- **修饰键三态**：`Ctrl / Alt / Win / Shift` 单击=按下后自动抬起；双击=字体加粗并粘滞锁定；再按一次恢复。
- **输入法快捷键**：内置 `Ctrl+空格`（切换主机输入法）、`Win+空格`（语言）、`Shift+空格`（全半角）等。
- **触控板**：单指相对移动、轻点左键、长按拖拽、双指滚轮/横向滚动、左/中/右键控制条。
- **边缘提示**：手指进入触控板边缘带震动一下（边沿触发 + 冷却，可在控制条关闭）。
- **保活与诊断**：前台服务防止系统注销 HID SDP、使用时保持亮屏、连接状态与诊断日志。

## 触控板移动流畅性

相对鼠标报告经过专门设计，避免蓝牙链路抖动造成指针卡顿：

- UI 线程只累加位移，专用高优先级线程按约 90Hz 合并发送，不做无界排队补发；
- 过期位移只做有限截断，既不整段丢失导致"卡一下"，也不全量回放导致"跳一大段"；
- `GET_REPORT` 只回复按钮状态、位移全 0，避免主机重放上一段位移；
- 振动放到后台线程执行，不会阻塞触摸采样。

## 构建

需要 JDK 21、Gradle 8.9、Android SDK 36（AGP 8.7）：

```sh
./gradlew assembleRelease
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/`。`local.properties` 里的 SDK 路径为本机路径，已加入 `.gitignore`。

`minSdk 28` / `targetSdk 34`，当前版本 `v1.7.3`（versionCode 11），release 使用本机 debug 密钥签名，便于直接安装覆盖。

## 使用

1. 在 Android 9+ 设备 Release/Debug APK，开启蓝牙并授予权限。
2. App 会启动前台服务保持 HID 注册；按返回键退出界面不会断开键盘，需在通知里点"停止并注销"。
3. 在电脑蓝牙设置里搜索并配对。Windows 可能把设备显示成"手机"，这是系统 CoD 决定的，只要设备管理器里出现 HID 键盘且能打字即为正常。
4. 首次连接或修改 HID 描述符后，需要**两端都删除配对记录再重新配对**（手机端"清除配对" + 电脑端删除设备），否则主机仍缓存旧 SDP。

## 已知限制

- 尚未做真机验证，不同 ROM / 主机兼容性可能有差异。
- 主机若开启"提高指针精确度"，触控板可能有轻微加速感；可在系统鼠标设置里关闭。
- 复合 HID（键盘 + 触控板）需要主机支持；兼容性不佳时可切回"仅键盘"模式（需重新配对）。
